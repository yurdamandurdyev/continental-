# Continental Bridge

Статический сайт без сборщика и JavaScript-зависимостей.

## Запуск
Откройте index.html в браузере или выполните из корня проекта:
    python -m http.server 8000
Затем откройте http://localhost:8000.

## Структура
- index.html — разметка и содержимое страницы.
- assets/css/base.css — переменные, сброс и общие стили.
- assets/css/sections.css — секции и компоненты.
- assets/css/responsive.css — адаптивные правила, подключаются последними.
- assets/js/navigation.js — шапка, мобильное меню и якоря.
- assets/js/animations.js — появление секций и счётчики.
- assets/js/services.js — раскрытие услуг.
- assets/js/faq.js — вопросы и ответы.
- assets/js/contact-form.js — демонстрационная форма и окно подтверждения.
- assets/js/redirect.js — переход со старого имени HTML.
- assets/images/ — изображения; brand/ — фирменные знаки; partners/ — партнёры.
- archive/ — исходный HTML для справки и неиспользуемые оригиналы изображений. Исходные относительные пути в архивном HTML не актуальны.

## Редактирование
Меняйте текст в index.html, оформление в CSS, поведение в соответствующем JS.
Скрипты изолированы и подключены с defer. Сборка не требуется.
Переключатель RU / 中文 в шапке переводит страницу без перезагрузки. Выбранный язык сохраняется в localStorage (cb-language). Китайские переводы находятся в assets/js/languages.js, адаптивные стили переключателя и китайская типографика — в assets/css/languages.css. Ключи словаря совпадают с исходным текстом index.html после нормализации пробелов: при изменении русского текста обновляйте соответствующий ключ. Официальные названия компаний и банковские реквизиты сохранены в исходном виде.
Кнопки обращения ведут на #request, ссылка «Контакты» — на #contacts.
Старый HTML-файл оставлен как переход для существующих закладок.

## Форма и внешние ресурсы
Форма пока не отправляет данные: показывает окно подтверждения и очищает поля.
Для реальных заявок необходимо подключить серверный обработчик.
Google Fonts и часть фотографий Unsplash загружаются из интернета.

## Публикация
Публикуйте index.html и каталог assets целиком. При необходимости сохраните старый HTML-переход.
Каталог archive публиковать не требуется.
